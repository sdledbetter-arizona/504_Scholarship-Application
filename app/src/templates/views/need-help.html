Frequently Asked Questions

If you're unable to log in, try the following steps:

  1. Make sure you are using the email address you registered with.
  2. Check that Caps Lock is not enabled when typing your password.
  3. Click the “Forgot Password” link (if available) on the login page to reset your password.
  4. If you still cannot log in, contact support using the form on this page. Include:
    • The email address you used to register
    • The browser and device you are using

To reset your password:

  1. Go to the Login page.
  2. Click on the “Forgot Password” link (if enabled by your system).
  3. Enter the email address associated with your account.
  4. Check your email inbox (and spam folder) for a reset link.
  5. Follow the instructions in the email to create a new password.

If you do not receive an email within 10-15 minutes, contact support with your name and registered email.

If no scholarships are appearing, try the following:

  1. Make sure your profile information is complete:
    • Major, GPA, expected graduation date
    • Demographic or eligibility information (if requested)
  2. Remove or loosen any filters (e.g., award amount, category, deadlines) and search again.
  3. Check the application period. Some scholarships may only appear during active application windows.
  4. If you still see no results, contact support and mention your major, GPA, and any filters you used.

Common reasons for upload issues and how to fix them:

  1. Check the allowed file types (e.g., PDF, DOCX, JPG). Convert the file to an accepted type.
  2. Make sure the file size is under the maximum limit (for example, 10 MB).
  3. Try renaming the file to something simple (e.g., Transcript_Spring2025.pdf).
  4. Use a stable internet connection and try again. Avoid public Wi-Fi if possible.
  5. If the problem persists, take a screenshot of any error and contact support with:
    • File name and type
    • Approximate file size
    • The scholarship or application you were trying to upload to

To view your application status:

  1. Log in to the Scholarship Matching System.
  2. Navigate to the “My Applications” or “Application History” page.
  3. Find the scholarship you applied for and review the status (e.g., Submitted, Under Review, Awarded, Not Selected).
  4. If the deadline has passed and your status has not changed after a reasonable period, contact support with:
    • The name of the scholarship
    • The date you submitted your application

If the site is not displaying correctly or you see an error message:

  1. Refresh the page and try again.
  2. Try a different browser (Chrome, Firefox, Edge) or device.
  3. Clear your browser cache and cookies and log in again.
  4. Take a screenshot of the error message.
  5. Contact support with:
    • The exact error message text (if any)
    • A screenshot of the issue
    • Your browser and device information
    • The page/URL you were on when it happened
